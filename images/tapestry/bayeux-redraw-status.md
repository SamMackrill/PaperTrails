# Generated Bayeux redraws

Five original PNG sheets were generated with the built-in imagegen tool on
1 October 2026 using `style-reference-bayeux.png` (approved study 8):

- `bayeux-early.png`
- `bayeux-revolutions.png`
- `bayeux-modern.png`
- `bayeux-context-chapters.png`
- `bayeux-winter-eras.png`

The exact prompts and generated source paths are preserved in
`bayeux-redraw-prompts.json`. The PNG bytes are unchanged. Initial inspection
confirms the expected seven/seven/seven/seven/five rows, mostly exposed linen,
coloured thread figures, narrow animal borders and no baked dates or headings.

The user approved the five source sheets and authorized runtime integration
after #68 merged. The follow-up uses all five in Tapestry mode, with measured
row crops and full-size WebP derivatives. PNG fallback retains the same subject,
era and crop. The Landscape sources and crop metadata remain unchanged.

Overview summaries use the central 112px of each first facet; the later facets
remain attached and open at fixed native proportions. Paired drawing briefs
and generation records include the measured crops. Latin headings remain in
HTML, with no dates baked into the sheets or shown in Tapestry captions.

Publication is held pending an in-prototype artwork preview and authorization
to publish. Source-sheet approval does not release that hold.
